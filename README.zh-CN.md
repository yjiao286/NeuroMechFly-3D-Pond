## 神经元个体

池塘里的每只果蝇都会飞、会走、会进食、会梳洗。只有一只还会**做决定**。大脑在
[`fly_brain.py`](fly_brain.py)：一个小型泄漏整合发放脉冲神经网络，每帧做子步进数值积分——
它不是装饰，环路不发放，果蝇就不动。

![金色方框标注的神经元果蝇，右侧是 GF / CX / REST 神经面板](docs/images/neural-fly.png)

*金框金字的果蝇是唯一由脉冲神经网络驱动的个体。右侧面板就是它四个环路的膜电位实时充放电
——这张图里青蛙已经走进巨纤维 170 的逃逸半径，GF 的条几乎满了。*

| 环路 | 作用 | tau | 触发条件 |
|---|---|---|---|
| **GF** 巨纤维系统 | 逃逸反射 | 0.05 s | 青蛙逼近到约 170，或跳跃阴影掠过 → 全速逃逸 0.85 s + 1.6 s 不应期 |
| **CX_L / CX_R** 中央复合体 | 转向 | 0.25 s | 左右振荡器竞争，差值带惯性 → 平滑、不重复的巡游 |
| **REST** 歇息回路 | 进食闸门 | 0.6 s | 悬停在食饵上空缓慢积累电位，超阈值才释放降落动作；2.5 秒没吃到或歇满 12 秒主动起飞 |
| 气味趋向 | 导航 | — | 饥饿时航向朝最近食饵偏转 |

阈值为 −52 mV，静息电位 −70 mV。按 `B` 打开面板，每根条表示该神经元离发放还有多远：
你可以看着 GF 随着你靠近而充能，再在它拔腿逃走之后看着它泄掉。

另外八只（`ScriptedFly`）是航点式脚本行为：觅食 → 降落啃食，青蛙靠近 110 内拔腿就逃。
神经元果蝇的反应距离远得多——因为决定它"受够了"的是阈值，而不是脚本。

## 果蝇大脑模拟浪潮中的位置

*Drosophila* 已经悄悄成为神经科学里最令人兴奋的模式物种：它是**第一个拥有完整成体大脑
连接组**的动物，而这些连接组正在被接进仿真身体里。

- **2024 · 整脑被测绘**：FlyWire 重建出成体果蝇大脑的 **139,255 个神经元、约 5 × 10⁷ 个
  化学突触**，并完成了细胞类型注释。
- **2024 · 整脑跑起来了**：连接组约束的计算模型复现了真实的感运动处理（糖感知与进食），
  也能预测视觉系统里单个神经元的反应。
- **2024–2025 · 大脑有了身体**：NeuroMechFly v2 与 FlyBody 把物理仿真的果蝇接到神经控制器
  下面，后者更是把肌肉接到了连接组推导出的运动神经元上。

这个仓库站在这个光谱"好玩"的那一端：4 个神经元、60 FPS、不用 GPU、不用引擎——
一只你端着青蛙真的能追着跑的果蝇。但既然不能只有卡通，仓库里**也安装并渲染了真实的
NeuroMechFly 身体**，包括它复眼的读数。从 4 个神经元的卡通走到科学模型，只差一条命令
（[见下文](#跑起来)）。

## 🧬 真·果蝇：FlyGym / NeuroMechFly

本文[最上方那张图](#-果蝇池塘-3d--fly-brain-pond-)**不是游戏素材**：它由
[`real_fly_demo.py`](real_fly_demo.py) 用 [FlyGym](https://neuromechfly.org)（EPFL 的有身体
果蝇感运动研究平台）自带的 micro-CT 网格组装，并在 MuJoCo 里离屏渲染出来。

### 力学：一只有关节、有附着、能推拉的果蝇

| 项目 | 模型里的实现 |
|---|---|
| **身体** | **micro-CT 扫描真果蝇**得到的 70 个体节：头与口器、触角（梗节/鞭节/芒）、六节腹部、平衡棒、翅、六条七节腿 |
| **关节** | **126 个转动自由度**，每个关节带刚度、阻尼与 armature。`JointPreset.ALL_BIOLOGICAL` 给每条腿 11 个自由度（coxa 3、trochanterfemur 2、tibia 1、tarsus1~5 各 1；远端跗节关节是被动的，和真果蝇一致） |
| **执行器** | demo 里共 **132 个**：每个自由度一个位置执行器（等价于肌肉的代理，官方教程用 CPG / 逆运动学 / RL 去驱动），外加 **6 个 tarsus5 足端附着执行器**——控制量 0→1 就是"抓住"或"松开"表面 |
| **接触** | 可按体节配置接触预设、逐腿接地传感器，以及逐体节接触力读数 |
| **物理** | MuJoCo 3.9，1 ms 步长；`flygym[warp]` 可换成 MuJoCo-Warp 后端，并行跑上千只果蝇 |

同一套 API 还带两个身体模型：**FlyBody**（[见上表](#站在这些工作的肩上)）用肌腱执行器补上
翅膀 pitch/roll/yaw 与腹部自由度，关节参数按生物力学标定；
**FlyMimic / `MusculoskeletalFly`** 用 **15 条 Hill 型肌肉 + 15 条空间肌腱**驱动左前腿。

### 神经：感觉 → 环路 → 肌肉

FlyGym 首先是一个神经科学平台：神经环路需要的每一条通道都暴露出来。

- **视觉** —— `add_vision()` 在左右复眼各放一个相机：**视场角 157°、每只眼 721 个小眼**，
  六边形采样与鱼眼畸变都按真实光学参数标定；读数按黄型/淡型两类小眼分开返回。
- **本体感觉** —— 全部 126 个自由度的关节角与角速度，以及身体、关节 site 的位姿。
- **机械感觉** —— 逐体节的接触力，也就是"每只脚现在踩到了什么"。
- **运动侧** —— 126 路关节目标 + 6 路附着通道；FlyBody 里连的是已发表的
  连接组推导出的运动神经元 → 肌肉映射。

![果蝇复眼看到的世界：鱼眼相机视图与 721 个小眼读数](docs/images/fly-vision.png)

*左：左眼相机（已做鱼眼校正）——能看到果蝇自己的前腿与方块地形。
右：同一帧经过 721 个小眼阵列采样后的读数，R = 黄型小眼、G = 淡型小眼。

### 跑起来

```bash
python3.12 -m venv .venv-flygym                    # flygym 2.1.0 需要 Python 3.12+
.venv-flygym/bin/pip install -r requirements-flygym.txt
.venv-flygym/bin/python real_fly_demo.py           # 生成上面两张图
```

脚本会打印它组装出来的模型：

```
NeuroMechFly: 70 个体节 / 126 个关节自由度 / 132 个执行器（含 6 个足端附着）/ 2 个复眼相机
```

游戏里的果蝇靠纯 pygame 跑 60 FPS，这只是物理仿真：每渲染一帧要一两秒，第一次运行时
Numba 还要 JIT 编译视网膜采样（约一分钟）。想要 GPU 后端装 `pip install "flygym[warp]"`；
想要用它训练运动策略装 `"flygym[rl]"`（Gymnasium + Stable-Baselines3）。

## 池塘本体

### 运行

需要 Python 3.10+（开发环境为 3.14）。只依赖 `pygame` 和 `numpy`——没有引擎、没有 OpenGL、
没有任何美术资源：每一个多边形都由 [`render3d.py`](render3d.py) 自己投影、排序、绘制。

```bash
git clone https://github.com/yjiao286/neuro-pond.git
cd neuro-pond

python -m venv .venv
.venv/bin/pip install -r requirements.txt   # Windows: .venv\Scripts\pip

.venv/bin/python main.py
```

### 操作

| 输入 | 功能 |
|---|---|
| 方向键 / WASD | 青蛙朝屏幕方向游动（自动转身） |
| 空格 | 跳跃（落在果蝇 60 单位内直接压杀） |
| 单击左键 / F | **吐舌头**（自动锁定朝向前方最近的目标；按住左键拖动则是平移视角，不会误触） |
| 按住右键拖动 | **旋转视角**（水平拖=环绕池塘旋转，垂直拖=调整俯仰角度 10°~62°） |
| 滚轮 | 缩放视角（拉近/拉远） |
| B | 神经面板：GF / CX_L / CX_R / REST 实时激活条 + 每个环路的含义备注 |
| M | 静音 |
| F11 | 全屏 / 还原窗口 |
| Esc | 退出 |

### 觅食机制

荷叶上会随机长出**食饵碎屑**（棕色颗粒）。果蝇闻味赶来、悬停，再由神经/脚本逻辑决定
降落啃食；碎屑被啃光会缩小消失，8~14 秒后在某片荷叶重新长出。
**专心进食/梳洗的果蝇不会注意你**——那是吐舌头的最好时机。池塘其余部分是
[`scenery.py`](scenery.py) 画出来的布景：水面焦散、涟漪、随波起伏的荷叶、荷花、浮萍、
沙岸堤壁、岩石、芦苇香蒲与灌木丛。

![池塘全景：荷叶、荷花、沙岸与果蝇](docs/images/preview.png)

### 果蝇的动作细节

每只果蝇都是 3D 建模：三节分节腹部、带描边高光的胸部、头部 + 触角、大复眼、口器、
六条髋→膝→足两段式关节腿、带翅脉的双翅。每种状态有专属动画：

- **飞行**：双翅展开高频振动，六足向后收拢飘摆
- **觅食行走**：三角步态（三足一组交替迈步），步频随移动速度变化
- **进食**：口器伸向食饵，**前足搭在碎屑上搓动辅助**，中足撑在叶面、后足微踏
- **梳洗（擦眼睛）**：落地后每隔几秒，抬起前足在复眼上画圈擦洗 1.2 秒（真实果蝇的
  梳理行为），擦眼期间暂停进食

## 防穿模是怎么做的

穿模的根源：画家算法按"多边形平均深度"排序，生物只要站在大片地面多边形中心的远侧，
就会被整片地面盖住。解决方案是**双层渲染**：

1. **地面层（先画）**：水面条带、焦散、荷叶各层、食饵、涟漪——平面物永远垫底；
2. **主层（后画，按深度排序）**：青蛙、果蝇、岸上立体的堤壁/岩石/芦苇/灌木。

另外所有落地生物对荷叶高度有感知（叶面随波起伏也实时跟随），脚踩叶面之上；
果蝇各部件（足/腹/胸/头/眼/翅）以不同高度与偏置绘制。

## 光照与材质是怎么做的

手写渲染不等于平涂。在 `render3d.py` 里有一层很小的"材质系统"：

- **全场景一盏主光**（`LIGHT_XY`）：所有球体与穹顶都朝同一个世界空间太阳方向打光，
  镜头怎么转，高光方向都保持一致。
- **`sphere()`**：边缘压暗的底色 + 向光侧逐层内缩提亮 + 镜面高光点 + 细描边——
  灌木、岩石、复眼、食饵碎屑从"扁圆片"变成有体积的球。
- **`dome()`**：同一套逻辑用在扁平的受光面上（青蛙背、头、荷叶、卵石）：边缘压暗 →
  内缩提亮 → 高光。
- **`soft_shadow()`**：把预生成的径向衰减贴图按投影尺寸缩放贴到地面，阴影是柔的而不是硬多边形。
- **水面分三层**：南北大气渐变底 + 漂移的细波纹短划 + 焦散闪点；**荷叶**有放射叶脉、
  近侧叶缘高光与叶背厚度；**草地**向远处雾化成层并散落深色草丛；天空带地平线暖光与飘动的云。
- 岸上的静态布景（堤壁、草地、卵石、岩石、灌木）按机位渲染进一张离屏缓存图层，
  于是"整池尽收眼底"的一帧在软件渲染下约 **18 ms**，只有摇摆的芦苇与草丛是每帧实时画的。

- **界面为中文**。字体会自动查找（先 macOS 系统中文字体，再走 `pygame.font.match_font`），
  在 Windows / Linux 上可能回落到不含中文字形的字体而显示成方框——把中文字体路径加进
  `main.py` 的 `FONT_PATHS`（`main.py:38`）即可解决。
- **无音频设备时会静音运行**：音效由 numpy 合成后经 `pygame.sndarray` 播放，没有声卡不影响游戏。
- **游戏里的神经元果蝇是游戏化模型**，不是生物物理仿真：四个手工整定的 LIF 环路复现的是
  "好玩、也便于理解"的行为。想要真的，见[真·果蝇](#-真果蝇flygym--neuromechfly)一节。
- **FlyGym 2.1.0 的坑**：它的逐腿接地传感器引用了不存在的元素名
  （`unrecognized name ... of sensorized object`），所以 `real_fly_demo.py` 里用
  `add_ground_contact_sensors=False` 编译。属上游问题，不是本仓库的；接触力仍然可以用
  `get_bodysegment_contact_forces()` 读到。
- 开发与测试环境为 macOS + Python 3.14 + pygame-ce 2.5.8，其余平台未做验证。
