# 🐸 果蝇池塘 3D · Fly Pond 3D 🪰

**一个用 Python 从零手写的 3D 池塘小游戏。** 你扮演一只青蛙：在荷叶间蹦跳、吐舌头，
捕食池塘里的果蝇。九只果蝇里有八只是普通的脚本 NPC，第九只由**脉冲神经网络**驱动，
会先"思考"再决定逃跑、巡游还是降落进食。

[English](README.md) · [简体中文](README.zh-CN.md)

![果蝇池塘 3D](docs/images/preview.png)

只依赖 `pygame` 和 `numpy`——没有 OpenGL、没有游戏引擎、没有任何美术资源。
每一个多边形都由 `render3d.py` 自己投影、排序、绘制出来。

## 亮点

- **自研 3D 渲染层** —— 透视投影、画家算法、近平面裁剪、深度偏置，以及一套
  **双层绘制顺序**，让青蛙站在大片地面多边形远侧时也不会被地面吞掉（不穿模）。
- **只有一只果蝇有大脑** —— 一个轻量 LIF 脉冲神经网络决定它的逃逸、巡游与进食；
  按 `B` 可以实时看到膜电位充放电的全过程。
- **动作细节丰富的果蝇** —— 三节分节腹部、髋膝足两段式关节腿、带翅脉双翅；
  飞行、三角步态行走、进食（前足搭在碎屑上搓动）、梳洗（前足擦复眼，真实果蝇行为）
  各有专属动画。
- **活的池塘** —— 水面焦散、涟漪、随波起伏的荷叶、荷花、浮萍、沙岸堤壁、岩石、
  草丛、芦苇香蒲、灌木丛与雾感天空。
- **程序化音效** —— 蛙鸣、落水、咔嚓、振翅嗡嗡、吐舌声全部由 numpy 在启动时合成，
  仓库里没有一个音频文件。
- **无头回归测试** —— `--selftest` 跑一只自动驾驶的青蛙，必须真的吃到虫才算通过。

## 运行

需要 Python 3.10+（开发环境为 3.14）。

```bash
git clone https://github.com/yjiao286/fly-pond.git
cd fly-pond

python -m venv .venv
.venv/bin/pip install -r requirements.txt   # Windows: .venv\Scripts\pip

.venv/bin/python main.py
```

## 那只"会思考"的果蝇

大脑在 [`fly_brain.py`](fly_brain.py)：一个小型泄漏整合发放（LIF）脉冲神经网络，
每帧做子步进数值积分。它不是装饰——环路不发放，果蝇就不动。

| 环路 | 作用 | tau | 触发条件 |
|---|---|---|---|
| **GF** 巨纤维系统 | 逃逸反射 | 0.05 s | 青蛙逼近到约 170 或跳跃阴影掠过 → 全速逃逸 0.85 s + 1.6 s 不应期 |
| **CX_L / CX_R** 中央复合体 | 转向 | 0.25 s | 左右振荡器竞争，差值带惯性 → 平滑、不重复的巡游 |
| **REST** 歇息回路 | 进食闸门 | 0.6 s | 悬停在食饵上空缓慢积累电位，超阈值才释放降落动作；2.5 秒没吃到或歇满 12 秒主动起飞 |
| 气味趋向 | 导航 | — | 饥饿时航向朝最近食饵偏转 |

阈值为 −52 mV，静息电位 −70 mV。按 `B` 打开面板，每根条表示该神经元离发放还有多远，
可以亲眼看到你走近金色果蝇时 GF"充电 → 发放"的全过程。

另外八只（`ScriptedFly`）是航点式脚本行为：觅食 → 降落啃食，青蛙靠近 110 内拔腿就逃；
神经元果蝇的反应距离远得多。

## 觅食机制

荷叶上会随机长出**食饵碎屑**（棕色颗粒）。果蝇闻味赶来、悬停，再由神经/脚本逻辑决定
降落啃食；碎屑被啃光会缩小消失，8~14 秒后在某片荷叶重新长出。
**专心进食/梳洗的果蝇不会注意你**——那是吐舌头的最好时机。

## 防穿模是怎么做的

穿模的根源：画家算法按"多边形平均深度"排序，生物只要站在大片地面多边形中心的远侧，
就会被整片地面盖住。解决方案是**双层渲染**：

1. **地面层（先画）**：水面条带、焦散、荷叶各层、食饵、涟漪——平面物永远垫底；
2. **主层（后画，按深度排序）**：青蛙、果蝇、岸上立体的堤壁/岩石/芦苇/灌木。

另外所有落地生物对荷叶高度有感知（叶面随波起伏也实时跟随），脚踩叶面之上；
果蝇各部件（足/腹/胸/头/眼/翅）以不同高度与偏置绘制。

## 果蝇的动作细节

3D 果蝇建模：三节分节腹部、带描边高光的胸部、头部 + 触角、大复眼、口器、
六条髋→膝→足两段式关节腿、带翅脉的双翅。每种状态有专属动画：

- **飞行**：双翅展开高频振动，六足向后收拢飘摆
- **觅食行走**：三角步态（三足一组交替迈步），步频随移动速度变化
- **进食**：口器伸向食饵，**前足搭在碎屑上搓动辅助**，中足撑在叶面、后足微踏
- **梳洗（擦眼睛）**：落地后每隔几秒，抬起前足在复眼上画圈擦洗 1.2 秒（真实果蝇的
  梳理行为），擦眼期间暂停进食；神经元果蝇梳洗时面板状态显示"梳洗"

## 关于"真实的果蝇大脑模型"

游戏 NPC 用的是轻量环路 SNN（60 FPS 实时）。此外
[NeuroMechFly (flygym)](https://neuromechfly.org)——EPFL 的**真实果蝇神经力学模型**
可以在 Python 3.12 + MuJoCo 环境中安装：

```bash
python3.12 -m venv .venv-flygym
.venv-flygym/bin/pip install -r requirements-flygym.txt
.venv-flygym/bin/python real_fly_demo.py     # 输出 real_fly.png
```

注意：flygym 2.1.0 刚发布、API 与官方教程差异较大，`real_fly_demo.py`（组包渲染真·果蝇）
目前在库内部 `compose/base.py` 的传感器命名处报错，属上游问题，建议等补丁或按官方教程调整。

## 已知限制

- **界面为中文**。字体会自动查找（先 macOS 系统中文字体，再走 `pygame.font.match_font`），
  在 Windows / Linux 上可能回落到不含中文字形的字体而显示成方框——把中文字体路径加进
  `main.py` 的 `FONT_PATHS`（`main.py:38`）即可解决。
- **无音频设备时会静音运行**：音效由 numpy 合成后经 `pygame.sndarray` 播放，没有声卡不影响游戏。
- **神经元果蝇是游戏化的行为模型**，不是生物物理仿真：三个手工整定的 LIF 环路复现的是
  "好玩、也便于理解"的行为。想要真正的果蝇模型请看上面的 NeuroMechFly 一节。
- 开发与测试环境为 macOS + Python 3.14 + pygame-ce 2.5.8，其余平台未做验证。
